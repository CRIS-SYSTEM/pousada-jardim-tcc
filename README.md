

\# Pousada Jardim — Controle de Estoque Setorizado



\## Sobre o projeto



Sistema desktop desenvolvido como Trabalho de Conclusão de Curso

em Sistemas de Informação, na Universidade de Franca (UNIFRAN).



O projeto tem como objetivo auxiliar a Pousada Jardim no

gerenciamento de produtos, setores e movimentações de estoque.



\## Tecnologias utilizadas



\- C#

\- .NET 10

\- Windows Presentation Foundation (WPF)

\- XAML

\- MySQL

\- MySqlConnector

\- Visual Studio



\## Funcionalidades



\- Autenticação e gerenciamento de usuários

\- Cadastro de categorias, produtos e setores

\- Controle de estoque por setor

\- Definição de estoque mínimo

\- Cadastro e controle de lotes e vencimentos

\- Movimentações de entrada, saída e transferência

\- Histórico de movimentações

\- Consultas e filtros combinados

\- Relatórios em PDF e CSV

\- Emissão de requisições físicas



\## Como executar



1\. Instalar o .NET 10 SDK e o MySQL.

2\. Criar ou restaurar o banco de dados da aplicação.

3\. Configurar o usuário e as permissões de acesso ao MySQL.

4\. Definir a variável de ambiente MYSQL\_PASSWORD.

5\. Abrir o projeto no Visual Studio.

6\. Restaurar as dependências e executar a aplicação.



Observação: o banco de dados deverá possuir a estrutura

compatível com a versão da aplicação.
